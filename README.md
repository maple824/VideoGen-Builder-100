# VideoGen Builder 100

一个面向视频生成方向的 100 天开源学习路径。

目标不是堆模型名字，而是从 Python、FFmpeg、图像/视频基础、PyTorch、Diffusion、Diffusers、ComfyUI、视频生成模型推理与评估，逐步走到可以交付可复现的视频生成项目作品集。

## 适合谁

- Python 基础不稳，但想进入 AI 视频生成方向的人
- 想系统学习 Text-to-Video / Image-to-Video / Video Workflow 的人
- 想把学习过程沉淀成 GitHub 作品集的人

## 课程结构

1. Day01-Day10：Python 与命令行基础
2. Day11-Day20：视频与媒体工程基础
3. Day21-Day30：图像处理与计算机视觉基础
4. Day31-Day40：深度学习基础
5. Day41-Day50：生成模型基础
6. Day51-Day60：Diffusers 与图像生成工程
7. Day61-Day70：视频生成模型推理
8. Day71-Day80：ComfyUI 与工作流工程
9. Day81-Day90：评估、安全与产品化
10. Day91-Day100：作品集项目与开源发布

## 最终项目

- Video Preprocess CLI
- Video Frame Analyzer
- Prompt-to-Image Lab
- Text-to-Video Inference Lab
- ComfyUI Workflow Zoo
- VideoGen Evaluation Dashboard

## 学习原则

- 每天必须有一个可检查产物
- 先跑通，再优化
- 不提交无法解释的代码
- 不公开私人素材和敏感数据
- 大视频文件不进 Git，仓库只保存代码、配置、截图、metadata 和小 demo
